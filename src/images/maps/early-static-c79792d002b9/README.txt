Early-era Civ13 scenario map sprite renders

Credit: the Civilization 13 team and original Civ13/Space Station 13 map and sprite contributors.
Source verified: https://github.com/Civ13/Civ13/tree/c79792d002b9a15b7cebd7735a43f6ac960ad4b2

Six authored maps, seven native z-layers. Actual DMM placements and DMI sprites composed offline; no AI artwork. Exact PNG bytes produced from 10d264e5896221b34949ee4b67c0fd2b94bde249 are reused after matching DMM/actual icon hashes and full placed-appearance pixel, draw and omission fingerprints against the verified source. Production-source labels remain truthful. No native game/server/client/compiler was run.

Runtime constructors, spawned objects, lighting, smoothing, animation, randomization and lower-z view projection are not executed. Every authored z is linked separately. Images use 32 pixels per tile and north-up coordinates; previews use nearest-neighbour resampling. No unresolved marker appears in this batch. Source voting does not prove current public-server availability. The task-local renderer is not included, so these files alone do not reproduce its pipeline. See asset-manifest.json for inputs, dimensions, hashes and limitations.
