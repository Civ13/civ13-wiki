Additional authored Nomads map sprite renders

Credit: the Civilization 13 team and original Civ13/Space Station 13 map and sprite contributors.
Source verified: https://github.com/Civ13/Civ13/tree/10d264e5896221b34949ee4b67c0fd2b94bde249

Eight authored variants, 20 native z-layers. Actual DMM placements and DMI sprites; no AI-generated artwork. Exact PNG bytes produced from 067478b82c7ad9f1b83759a221e6f22080ba865a were reused after matching each DMM SHA and complete placed-appearance pixel, draw and omission fingerprints against current source. Original source labels remain truthful. No native game/client/compiler was run.

The pages distinguish authored variants from current hosting and the standard map vote. Frozen Wasteland has an authored metadata file that is not included in the default DME; it is labeled archived. Gaia surface is native z2; underground z1. Mountain retains all eight authored levels.

Runtime constructors, lighting, generated objects, smoothing, animation, randomization and lower-z view projection are not shown. Full-resolution layer files use 32 pixels per tile and north-up coordinates; previews use nearest-neighbour resampling. No unresolved markers occur in this batch. The task-local renderer is not included, so these files alone do not reproduce its pipeline. See asset-manifest.json for exact inputs, output dimensions, hashes and limitations.
