# Role Guides

Guides for roles with special responsibilities. Read the guide before taking the role, because other players depend on you.

## Colony and settlement roles

- [Governor](Governor.md): write the colony's laws and manage its treasury.
- [Merchant](Merchant.md): order supplies from overseas and export the colony's goods.
- [Colony Medic](Colony_Medic.md): diagnose and treat colonists and run the clinic.
- [Blacksmith](Blacksmith.md): forge weapons, armor and tools on the colony's only usable anvils.

See [Colony Building](gamemodes/Colony_Building.md) for how these roles fit together.

## Combat roles
