Static Civ13 map sprite renders

Credit: the Civilization 13 team and the original Civ13/Space Station 13 map and sprite contributors.
Source: https://github.com/Civ13/Civ13/tree/58404f5bd16e3fed80f1d9844c5db3edd144942c

These PNGs compose actual repository DMM placements and DMI sprites using the task-local Civ13 source-only Python/Pillow renderer 1.0. They are static map artwork, not gameplay screenshots. No AI-generated imagery was used.

Original map and sprite copyrights, licenses and individual attribution notices remain with their respective authors. Rendering does not transfer those rights or relicense the images under this wiki's MIT license. LICENSE-Civ13.txt preserves the source repository's AGPL-3.0 license notice; it is not a new assertion that every upstream asset has that same license.

The source repository contains an explicit CC BY-SA 3.0 notice for icons/obj/bark.dmi. That sprite is not used by the six map render sets in this directory. The unchanged source notice remains available at the source revision above. No additional per-asset credit file was found in the source icons directory for these maps. Existing sprite metadata and public source history remain the attribution reference.

See asset-manifest.json for the exact DMM identities, layer lists, output hashes, and rendering limitations. The source revision and asset hashes identify the inputs; the task-local renderer is not included in this asset directory, so these files alone do not reproduce the rendering pipeline.
