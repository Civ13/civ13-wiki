Static Civ13 map sprite renders - additional corrected map sets

Credit: the Civilization 13 team and original Civ13/Space Station 13 map and sprite contributors.
Source: https://github.com/Civ13/Civ13/tree/067478b82c7ad9f1b83759a221e6f22080ba865a

Actual DMM placements and DMI sprites composed by Civ13 source-only Python/Pillow renderer 2.0. No AI-generated artwork. These are static map layouts, not gameplay screenshots. Runtime lighting, constructors, generated objects, smoothing, animation, randomization and later sprite changes are not executed.

Original map and sprite copyrights, licenses and individual credit notices remain with their authors. These images are not relicensed under this wiki's MIT license. LICENSE-Civ13.txt preserves the source repository's AGPL-3.0 notice without asserting that every upstream asset has that same license. The source tree's explicit bark sprite CC BY-SA3.0 credit is preserved unchanged as bark.dmi.LICENSE.txt; retaining that notice does not claim the sprite appears in every render.

The old static-58404f5bd16e PNGs and their six map sections remain unchanged. Their full PNG bytes equal current corrected outputs for those maps; original source provenance is retained. The source revisions linked in both directories identify the compared inputs; static image equality does not establish runtime or public-server equivalence.

Wiki-only overview images remove the top72px source/version label bands from already-rendered layer previews, resize map pixels with nearest-neighbour interpolation and add only exact filename/z labels. Full PNGs preserve the original output bytes. See asset-manifest.json for exact maps/layers and file hashes. The task-local renderer is not included in this asset directory, so these files alone do not reproduce the rendering pipeline.
