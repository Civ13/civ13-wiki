Static Civ13 TDM-server map sprite renders

Credit: the Civilization 13 team and original Civ13/Space Station 13 map and sprite contributors.
Source: https://github.com/Civ13/Civ13/tree/067478b82c7ad9f1b83759a221e6f22080ba865a

Actual DMM placements and DMI sprites composed by the source-only Python/Pillow renderer 2.0. No AI-generated artwork. These are static map layouts, not gameplay screenshots. Runtime lighting, constructors, generated objects, smoothing, animation, randomization and later sprite changes are not executed. Every authored z-layer of each included map is linked separately. Overviews use nearest-neighbour resampling and exact DMM filename/z labels.

Original map and sprite copyrights, licenses and individual credit notices remain with their authors. These images are not relicensed under this wiki's MIT license. LICENSE-Civ13.txt preserves the source repository's AGPL-3.0 notice without asserting that every upstream asset has that same license. The source tree's explicit bark sprite CC BY-SA 3.0 credit is preserved unchanged as bark.dmi.LICENSE.txt; retaining that notice does not claim the sprite appears in every render.

See asset-manifest.json for DMM identities, source hashes, layer lists, image dimensions and hashes. Source configuration does not establish runtime or public-server availability. The task-local renderer is not included in this asset directory, so these files alone do not reproduce the rendering pipeline.
